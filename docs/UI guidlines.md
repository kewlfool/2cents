Design a **minimal, dense, productivity-focused UI** with an emphasis on maximizing usable content area and minimizing scrolling.

Requirements:

* No onboarding copy, helper text, tips, empty-state essays, or suggestion text unless absolutely necessary for functionality.
* Eliminate visual clutter and decorative UI.
* Avoid “card inside card” layouts entirely. Nested containers waste space and create visual noise.
* Use flat, clean sections with subtle separators instead of heavy borders/shadows.
* Prioritize information density while maintaining readability.
* Main content must occupy the maximum possible viewport area.
* Minimize padding, margins, oversized headers, and excessive whitespace.
* Reduce scrolling as much as possible:

  * Compact vertical rhythm
  * Sticky controls where useful
  * Multi-column layouts on desktop
  * Collapsible secondary sections
  * Inline editing/actions instead of modal-heavy flows
* Keep navigation lightweight and space-efficient:

  * Slim sidebar or compact top nav
  * Avoid giant hero sections
  * Avoid oversized toolbars
* Typography should be compact and legible:

  * Tight but readable line-height
  * Clear hierarchy without huge text
* Forms and controls should be compact:

  * Small consistent input heights
  * Dense tables/lists
  * Inline labels where appropriate
* Optimize for keyboard/mouse power users:

  * Fast scanning
  * Predictable layout
  * Minimal clicks
  * Keyboard shortcuts if relevant
* Responsive behavior:

  * Desktop should maximize information density
  * Mobile should remain clean without unnecessary stacking explosions
* Use subtle visual hierarchy instead of large containers:

  * Dividers
  * Background contrast
  * Typography weight
  * Spacing
* Avoid trendy dashboard aesthetics that sacrifice usability for appearance.
* Prefer:

  * linear layouts
  * split panes
  * docked panels
  * compact tables/lists
  * persistent context
* The interface should feel:

  * fast
  * focused
  * utilitarian
  * efficient
  * professional
* Inspiration:

  * developer tools
  * IDEs
  * trading terminals
  * admin panels
  * power-user software
* Do NOT design like:

  * marketing websites
  * mobile-first card feeds
  * overly spacious SaaS dashboards
  * Dribbble-style concept UIs

Goal: maximize productivity-per-pixel. Every UI element must justify the space it consumes.
